# Anna Burgess Portfolio

Upload all files and folders in this directory to the root of the GitHub Pages repository. Keep `Anna_Burgess_Resume.pdf` beside `index.html`.

## Adding project photos

Put images in `assets/images/` using the filenames already referenced by the site. For example:

- `fud-1.jpg`, `fud-2.jpg`, `fud-3.jpg`
- `sphinx-1.jpg`, `sphinx-2.jpg`, `sphinx-3.jpg`
- `yellow-jacket-1.jpg`, etc.

If an image is missing, the site intentionally shows a placeholder that tells you the expected filename.

## Editing project details

Project descriptions and gallery image lists live near the top of `assets/script.js` in the `PROJECTS` object. Project card text is currently generated into the HTML files.
